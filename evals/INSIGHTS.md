# Insights — Evals Harness

> Draft — entries are under human review. Last updated: 2026-08-20.

- `2026-08-20` **What Doesn't Work:** Grounding strings that match invented rule IDs (e.g. `inward-only-dependencies`, `di-discipline`) fail 100% of the time in `agentTask` — the agent reads real CLAUDE.md/INSIGHTS.md, uses *their* language, and never emits labels that only exist in the agent's own system prompt. Ground on tokens that must appear in ANY correct answer: evidence from the diff (`FastifyReply`, `readFileSync`), verdict keywords (`FAIL`, `PASS`), or phrases from the actual docs — `evals/agents/architecture-reviewer/architecture-reviewer.cases.ts`
- `2026-08-20` **Codebase Patterns:** `agentTools()` includes `Bash` in `MUTATING_TOOLS` and strips it silently for every `agentTask` run. Any agent whose procedure starts with `git diff --name-only` (e.g. architecture-reviewer) cannot scope itself by git in eval — it must fall back to parsing the diff embedded in the prompt. Without Bash, a scope-naive agent may `Glob server/src/modules/**` and review the entire real repo — `evals/src/artifacts/load.ts:43`
- `2026-08-20` **What Doesn't Work:** When an agent definition says "report no architecture-relevant changes and stop", models consistently write `Verdict: N/A` rather than `Verdict: PASS`. Grounding on `["PASS"]` then blocks the judge on every early-exit run. Fix in two places: (1) state explicitly in the agent definition that the early-exit verdict must be `PASS`, not `N/A`; (2) ground on the phrase the model *actually* produces (`"No architecture-relevant"`) — `evals/agents/architecture-reviewer/architecture-reviewer.cases.ts`
- `2026-08-20` **What Doesn't Work:** A prose rule "no fix suggestions" in an agent definition is insufficient — models append "Required Actions Before Merge" / "Recommended Actions" sections regardless. The rule must include a concrete negative example listing the exact forbidden section titles, otherwise the eval case that checks for their absence will fail consistently — `.claude/agents/architecture-reviewer.md`
